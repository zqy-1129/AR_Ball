# .tools —— 本机辅助脚本

这些脚本**不参与 App 构建**，只在开发/验证阶段跑在本机构建机上，依赖 `adb` 与 Python 3。
目录里的日志、截图、录屏、SDK 压缩包都是临时产物，已被 `.gitignore` 排除，只有 `*.py` 会入库。

| 脚本 | 作用 |
| --- | --- |
| `drive.py` | **传感器注入驱动**。先按目标相机姿态 `(方位角, 俯仰角)` 解析地算出加速度计 / 磁力计读数，再通过模拟器控制台注入 —— App 走的是完全真实的传感器代码路径，而不是被喂一个假姿态。<br>`sweep`：绕物体成带环绕；`aim`：精确瞄准若干方向；`pose`：设置单个姿态；`record`：录屏 |
| `record_demo.py` | **一键录屏**：安装 APK → 启动 → 环绕 → 读 logcat 判断覆盖率 → 按「最脆弱光点」顺序闭环补扫 → 拉回 mp4 |
| `plan.py` | **离线覆盖模型**：复现 App 的球面采样与覆盖判定，评估不同俯仰带规划的 `minU`（最脆弱光点余量）与覆盖率 |
| `analyze.py` | 对 `plan.py` 的输出做统计汇总 |
| `probe_png.py` | **纯 Python 解 PNG**，量截图里自绘 HUD 控件的真实像素矩形。从 adb 点自绘按钮前先用它定位，别按屏幕比例猜 |

## 常用命令

```bash
# 绕物体水平转一圈（1 带 8°、3° 步长、5 Hz 注入速率）—— 一圈即可拍满 8 个面
python .tools/drive.py sweep 1 3 0 1 "8"

# 精确瞄准若干方向（补扫 / 定位某个面）
python .tools/drive.py aim "214.1:-69.9;358.3:43.0" 0.3

# 一键：安装 → 启动 → 环绕 → 闭环补扫 → 录屏 → 拉回 mp4
python .tools/record_demo.py <apk路径> <输出mp4路径>

# 离线评估 7 条俯仰带的鲁棒性
python .tools/plan.py
```

> 需要设备与 adb 在 `PATH` 上。多设备时给 adb 加 `-s <serial>`。
